# Как запустить EstatePulse

## Через Docker Desktop

1. Скачай репозиторий и открой терминал в его папке.
2. Скопируй `.env.example` в `.env` (PowerShell: `Copy-Item .env.example .env`).
3. Сгенерируй секрет командой ниже и вставь результат после `JWT_SECRET=` в `.env`:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

4. Если нужен администратор публикаций, заполни `ADMIN_EMAIL` и `ADMIN_PASSWORD` (минимум 12 символов). Если нет — оставь оба поля пустыми.
5. Запусти:

```bash
docker compose up --build
```

Первый запуск устанавливает зависимости и обучает модель. После запуска открой **http://localhost:3000**. Оценка работает для Астаны; данные — январь 2026 года. Для сохранения результатов зарегистрируйся и войди.

Остановка: `docker compose down`. Не добавляй `-v`, если хочешь сохранить базу и модель.

## Без Docker

Нужны Python 3.12, Node.js 22.12+ и работающий MongoDB 7. Из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r ml/requirements-dev.txt
python -m ml.train
Copy-Item backend/.env.example backend/.env
```

Заполни `JWT_SECRET` в `backend/.env`. Для существующей базы укажи её адрес в `MONGO_URI`; если раньше база называлась `blogdb`, сохрани это имя в URI.

В трёх терминалах:

```powershell
# 1. ML-сервис; активируй .venv
python -m uvicorn ml.service.main:app --host 127.0.0.1 --port 8000
```

```powershell
# 2. Backend
npm ci --prefix backend
npm start --prefix backend
```

```powershell
# 3. Frontend
npm ci --prefix frontend
npm start --prefix frontend
```

Открой **http://localhost:3000**. На Linux/macOS окружение активируется командой `source .venv/bin/activate`, а файлы копируются командой `cp`.

## Что изменилось

- Категории дома/ремонта форма получает от модели: расхождения английских и русских значений устранены.
- Добавлены район и год постройки; оценка ограничена Астаной.
- Пропуски заполняются без использования тестовой выборки; квартиры разделяются по группам комплексов/адресов.
- Обучение сравнивает baseline, Random Forest и Extra Trees; текущий выбранный вариант — Extra Trees.
- Старые записи истории читаются, но старую модель нужно обучить заново.
- Убраны стандартный JWT-секрет и создание администратора с паролем `admin`.
- Frontend работает на Vite. Настройка отдельного API теперь называется `VITE_API_URL`.
- API публикаций находится под `/api/posts`; страницы сайта остались под `/posts/...`.

## Проверка и частые ошибки

- **Model missing:** выполни `python -m ml.train` из корня репозитория.
- **JWT_SECRET:** секрет не заполнен или слишком короткий; нужен случайный ключ минимум 32 символа.
- **Startup failed:** проверь доступность MongoDB и `MONGO_URI`.
- **Сервис оценки недоступен:** проверь терминал FastAPI и `ML_SERVICE_URL`.
- **Ошибка 422:** введены параметры вне поддерживаемого диапазона или этаж выше этажности.
- **Старая сессия:** после смены JWT-секрета войди заново.

Если в старой базе уже создан администратор со стандартным паролем, его пароль необходимо отдельно заменить: изменение `.env` не меняет существующий пароль. Публичная регистрация не выдаёт права администратора.

Команды тестирования и описание модели находятся в основном README. Метрики показывают качество на исторической тестовой выборке, а не гарантированную погрешность любой оценки сегодня.
